# Character Replacement Tool in VB.NET

A beginner-friendly VB.NET console application that allows users to replace a selected character inside a string with another character.

This project demonstrates basic string manipulation techniques using built-in VB.NET methods.

---

## Features

- Accepts user input from the console
- Replaces a selected character with another character
- Uses reusable functions
- Demonstrates string processing in VB.NET
- Simple and beginner-friendly console interface

---

## Tech Stack

- VB.NET
- .NET 8
- Console Application

---

## How It Works

The program:

1. Takes a string from the user
2. Asks which character should be replaced
3. Asks for the replacement character
4. Uses the built-in `.Replace()` method
5. Displays the updated string
