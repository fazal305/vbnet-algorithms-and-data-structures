# VB.NET User Defined Data Types Practice

A beginner VB.NET practice collection focused on user-defined data types, enums, classes, and basic object-oriented programming concepts.

This repository contains small console-based projects created while learning Visual Basic .NET and A-Level programming fundamentals.

---

## Topics Covered

- VB.NET console applications
- User-defined data types
- Classes and properties
- Enums
- Basic object-oriented programming
- Project structure in .NET
- Console output

---

## Projects Included

### Contact Detail Class
A simple VB.NET class that stores contact information such as name, area, and house number.

### Student Data Type
A custom student data structure with properties such as student ID, email, and club membership values.

### Months Enum
A custom `Months` enum demonstrating how named constants can be used in VB.NET programs.

---

## Tech Stack

- VB.NET
- .NET 6
- .NET 8
- Visual Studio

---

## How To Run

1. Clone or download this repository.
2. Open the `.sln` or `.vbproj` file in Visual Studio.
3. Build the project.
4. Run the console application.
